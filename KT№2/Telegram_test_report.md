## 4. Тест-кейсы

### Тест-кейс 1. Отправка текстового сообщения

**Предусловие:** Telegram Desktop установлен, пользователь авторизован, открыт существующий чат.

**Шаги:**
1. Открыть Telegram Desktop.
2. Выбрать чат.
3. Ввести текстовое сообщение.
4. Нажать кнопку отправки.
5. Проверить содержимое чата.

**Ожидаемый результат:**  
Введенное сообщение появляется в выбранном чате и отображается без ошибок.

**Фактический результат:**  
Сообщение успешно отправляется и отображается в чате.

**Статус:** PASS

---

### Тест-кейс 2. Поиск пользователя

**Предусловие:** Telegram Desktop запущен, пользователь авторизован.

**Шаги:**
1. Нажать на поле поиска.
2. Ввести имя или username пользователя.
3. Просмотреть результаты поиска.
4. Выбрать найденного пользователя.

**Ожидаемый результат:**  
Telegram отображает подходящие результаты поиска, после выбора открывается чат с пользователем.

**Фактический результат:**  
Пользователь находится через поиск, его чат открывается корректно.

**Статус:** PASS

---

### Тест-кейс 3. Отправка изображения

**Предусловие:** открыт чат, на компьютере имеется изображение.

**Шаги:**
1. Открыть нужный чат.
2. Выбрать изображение для отправки.
3. Подтвердить отправку.
4. Дождаться окончания загрузки.
5. Проверить сообщение в чате.

**Ожидаемый результат:**  
Выбранное изображение загружается и появляется в сообщении чата.

**Фактический результат:**  
Изображение успешно загружается и отображается в чате.

**Статус:** PASS

---

### Тест-кейс 4. Отправка и скачивание файла

**Предусловие:** открыт чат, на компьютере имеется файл для отправки.

**Шаги:**
1. Открыть нужный чат.
2. Выбрать файл.
3. Отправить файл.
4. Дождаться завершения загрузки.
5. Скачать отправленный или полученный файл.
6. Проверить наличие файла на компьютере.

**Ожидаемый результат:**  
Файл успешно отправляется, скачивается и сохраняется на компьютере без повреждения.

**Фактический результат:**  
Файл успешно отправляется и сохраняется после скачивания.

**Статус:** PASS

---

### Тест-кейс 5. Работа с уведомлениями

**Предусловие:** Telegram Desktop запущен и пользователь авторизован.

**Шаги:**
1. Открыть настройки уведомлений выбранного чата.
2. Оставить уведомления включенными.
3. Получить новое сообщение.
4. Проверить появление уведомления.
5. Отключить уведомления для этого чата.
6. Получить новое сообщение и проверить уведомление.

**Ожидаемый результат:**  
При включенных уведомлениях появляется уведомление о новом сообщении. После отключения уведомления для выбранного чата не отображаются.

**Фактический результат:**  
Уведомления работают в соответствии с установленными настройками.

**Статус:** PASS
